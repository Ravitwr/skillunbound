# Contributing to Skill Unbound

Skill Unbound accepts corrections and original additions through reviewable pull requests.

## Resource corrections

Include the canonical URL, title, publisher or creator, access state, the date you opened it, the affected milestone, and why the replacement is stronger. Do not paste lesson transcripts or protected course copy.

## Curriculum proposals

State the learner, prerequisites, measurable outcomes, weekly build deliverables, capstone, rubric, and licensing or source notes. All prose and assignments must be original.

## Code changes

1. Create a focused branch.
2. Run `npm test` and test keyboard navigation at mobile and desktop widths.
3. Explain privacy or network behavior for every new tool.
4. Do not add analytics, uploads, AI providers, or user-data collection without an explicit privacy and threat review.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
